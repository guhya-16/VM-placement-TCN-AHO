## 5. CPU Physical Units & Bounding

* **Units**: All CPU values (`current_cpu`, `predicted_cpu_*`, `predicted_mean_cpu`, `predicted_peak_cpu`, `volatility_score`) are expressed in **CPU Utilization Percentages ($[0.0\%, 100.0\%]$)**, NOT MHz.
* **Option B Physical Clipping**: Multi-step TCN regression outputs in `risk_state.csv` have been strictly clipped to $[0.0\%, 100.0\%]$ by Person 1. You will never encounter negative CPU percentages (`min = +0.0060%`).
* **Host Modeling**: When calculating host utilization, multiply `predicted_mean_cpu` by the VM's assigned capacity or treat it directly as host percentage allocation:
  $$U_{\text{PM}, j}(t) = \sum_{i \in \text{VMs placed on PM } j} \text{predicted\_mean\_cpu}_i(t)$$

## 6. Risk State Interpretation & Mathematical Formulation

The risk state partitions VMs into operational categories based on validation-frozen thresholds:

```text
====================================================================================================
                                   RISK SCORE FORMULATION
====================================================================================================
volatility_norm = min(1.0, volatility_score / 4.675352)
spread_norm     = min(1.0, (max(y_fc) - min(y_fc)) / 3.382352)

risk_score = 0.60 * volatility_norm + 0.40 * spread_norm

tau_low  = 0.029545  (33.3rd percentile of validation sliding windows)
tau_high = 0.174569  (66.7th percentile of validation sliding windows)

- LOW:    risk_score < 0.029545   (Stable, predictable workload)
- MEDIUM: 0.029545 <= risk_score < 0.174569 (Moderate volatility or gradual trend)
- HIGH:   risk_score >= 0.174569  (Highly turbulent or rapid projected spike)
====================================================================================================
```

> ⚠️ **PERSON 3 INVARIANT**: You must **NOT** alter the calibration parameters ($4.675352$, $3.382352$, $0.029545$, $0.174569$). They are scientifically frozen from historical validation windows to guarantee zero test-set leakage.

## 7. Recommended Column Usage in Adaptive HO

| Column Name | Recommended Optimization Role in AHO |
| :--- | :--- |
| `predicted_mean_cpu` | **Host Power & Energy Objective**: Feed into PM power curve $P(u) = P_{\text{idle}} + (P_{\text{max}} - P_{\text{idle}}) \cdot u$. Evaluates expected energy consumption over the upcoming hour. |
| `predicted_peak_cpu` | **Hard Capacity Constraint**: Enforce $\sum \text{predicted\_peak\_cpu}_i \le \text{Capacity}_{\text{PM}} \times \text{Threshold}$ to prevent SLA violations during burst periods. |
| `volatility_score` | **Turbulence Penalty / Colocation Constraint**: Prevent placing multiple high-volatility VMs on the same physical host. |
| `predicted_std_cpu` | **Trajectory Dispersion**: Distinguishes flat steady workloads from steep ramps. |
| `risk_score` | **Continuous Parameter Adaptation**: Dynamically scale HO exploration/exploitation step size $\alpha$ or inertia weight: $\alpha_t = f(\overline{\text{risk\_score}}_t)$. |
| `risk_state` | **Categorical Safety Buffers**: Set dynamic PM safety headroom: e.g., 5% buffer for `LOW`, 10% for `MEDIUM`, 20% for `HIGH`. |

## 10. Placement Decision Semantics

At each decision cycle:
1. Filter `risk_state.csv` for the current `decision_timestamp` $t$.
2. This yields the cohort of active VMs requiring placement at time $t$ (e.g., 7 active VMs).
3. Extract each VM's predicted workload (`predicted_mean_cpu`, `predicted_peak_cpu`) and risk profile (`risk_score`, `risk_state`).
4. Execute Adaptive HO to assign each VM to an active PM ($j \in [1 \dots M]$).
5. Output the mapping to `placement.csv`.

## 11. Suggested Person 3 Internal Representation (Python Example)

```python
import pandas as pd
from dataclasses import dataclass

@dataclass
class VMWorkloadProfile:
    vm_id: str
    decision_timestamp: int
    current_cpu: float
    predicted_mean: float
    predicted_peak: float
    volatility: float
    risk_score: float
    risk_state: str

# Ingestion function for Person 3
def load_placement_cohort(csv_path: str, timestamp: int) -> list[VMWorkloadProfile]:
    df = pd.read_csv(csv_path)
    cycle_df = df[df["decision_timestamp"] == timestamp]
    
    cohort = []
    for _, row in cycle_df.iterrows():
        cohort.append(VMWorkloadProfile(
            vm_id=row["vm_id"],
            decision_timestamp=int(row["decision_timestamp"]),
            current_cpu=float(row["current_cpu"]),
            predicted_mean=float(row["predicted_mean_cpu"]),
            predicted_peak=float(row["predicted_peak_cpu"]),
            volatility=float(row["volatility_score"]),
            risk_score=float(row["risk_score"]),
            risk_state=row["risk_state"]
        ))
    return cohort
```
